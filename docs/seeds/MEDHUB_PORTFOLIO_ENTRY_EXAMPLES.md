# MedHub Portfolio Entry Types — UH Psychiatry Examples

**Source:** MedHub Portfolio → "+ New Portfolio Entry" dropdown (UH)  
**Purpose:** What residents actually log in MedHub vs what FISCMAK captures separately  
**Related:** `MEDHUB_UH_EVAL_MAPPING.md`, career engine (Capture → Map → Build → Launch)

---

## Key distinction

| System | Question it answers |
|--------|---------------------|
| **MedHub Portfolio** | "Did the resident document required/scholarly/QI activities for the program record?" |
| **FISCMAK Achievement Vault** | "What career evidence did this work produce — and what can I export?" |

**Strategy:** Don't ask residents to log everything twice.  
- **Tier 1 formal** (publications, QI, grants) → import or mirror from MedHub when export exists  
- **Invisible work + reflection + career narrative** → FISCMAK-native (MedHub doesn't capture well)  
- **Self Reflection / Learning Plan** in MedHub → Tier 3; FISCMAK can **sync or parallel** with richer prompts

## Entry type catalog with psychiatry examples

### General Entry
**MedHub use:** Catch-all when no other type fits.  
**Psychiatry examples:**
- Summary of outpatient continuity clinic experience for the semester  
- Reflection on first CL month  
- Note about participating in department wellness committee  

**FISCMAK:** Map to **Growth Engine** or **Clinical Craft**; prefer specific types when possible. Often better as FISCMAK rotation debrief than generic MedHub entry.

---

### Rotation Notes
**MedHub use:** Documentation tied to a specific rotation block.  
**Psychiatry examples:**
- CL month: capacity evaluation learning points, consult workflow  
- CAPU: family meeting skills, developmental formulation  
- Psych ED: risk assessment and disposition cases (de-identified)  
- VA CT6: acute stabilization and team leadership  

**FISCMAK:** Overlaps **Rotation Debrief Builder** — FISCMAK can generate text resident pastes into MedHub, or import if MedHub export includes portfolio.

---

### Procedure/Patient Notes
**MedHub use:** Procedure logs or significant patient encounters (program-dependent).  
**Psychiatry examples:**
- First independent capacity evaluation (supervised)  
- ECT observation/consent process (UH Interventional rotation)  
- Clozapine initiation monitoring case  
- Emergency involuntary hold and hearing process (de-identified)  
- Ketamine/TMS candidacy evaluation note  

**FISCMAK:** **Clinical Craft** vault → CV bullet / interview story. Tag: `capacity`, `interventional`, `risk_assessment`.

---

### Publication — Book Chapter
**Psychiatry examples:**
- Chapter on delirium in medically ill patients (PGY-3+)  
- Handbook chapter on buprenorphine in primary care settings  

**FISCMAK:** **Knowledge Base** / scholarship track. Tier 1 — auto from CV enrichment (ORCID/PubMed) when possible.

### Self Reflection
**MedHub use:** Program-required reflective entries.  
**Psychiatry examples:**
- After difficult patient death on inpatient unit  
- Countertransference in long-term psychotherapy patient  
- Response to feedback on diagnostic precision (Walker OP eval)  

**FISCMAK:** **Tier 3 — private by default** in FISCMAK vault. Optionally share at semiannual review. Do not feed to PD dashboard as surveillance.

## What FISCMAK should NOT duplicate in MedHub

Residents already hate double entry. FISCMAK-native capture for:

| Activity | Why not MedHub only |
|----------|---------------------|
| Invisible work (coordination, advocacy, extra teaching) | No MedHub type fits well |
| Supervision-to-story | Too granular for portfolio |
| Block-end career debrief | MedHub rotation notes are compliance-toned |
| Letter writer packet assembly | Not a MedHub feature |
| Milestone-to-career translation | Motivation layer |

**Workflow:** FISCMAK captures → resident **exports** → paste into MedHub **only when program requires** (Learning Plan, Self Reflection, QI summary).

## Example: one rotation, multiple MedHub entries (CL block)

After a **CL block**, a PGY-2 might add in MedHub:

1. **Rotation Notes** — summary of CL month  
2. **Procedure/Patient Notes** — capacity evaluation case  
3. **Presentation - Local** — CL case conference  
4. **Self Reflection** — uncertainty in medical setting  
5. **Learning Plan** — improve consult note timeliness  

**FISCMAK** generates drafts for 1, 4, 5 from capture prompts; tags all as **Relational Leadership + Systems Impact**; produces CV bullets without five separate blank forms.

## Import priority for FISCMAK (MedHub portfolio)

| Priority | Types | Why |
|----------|-------|-----|
| **P1** | QI, Safety, Research, Publications, Presentations | Tier 1 scholarship/systems evidence |
| **P2** | Learning Plan, Continuity Clinic Log, Teaching Skills | ILP + outpatient trajectory |
| **P3** | Self Reflection, Rotation Notes | Tier 3 — resident-owned |
| **P4** | General Entry | Parse only if structured |
