## THE FIVE OPTIONS: NAMING STRATEGY

The naming follows a pattern: **[VERB] Your [NOUN]**

Each option has:
1. **Action verb** (what the user does)
2. **Subject** (what they explore/create)
3. **Icon** (visual anchor)
4. **Button color** (visual grouping)
5. **Mak greeting** (conversational entry point)
6. **Page it links to** (data destination)

---

## OPTION 1: DISCUSS YOUR ENERGY

### Naming Breakdown
```
Verb:        DISCUSS (conversational, open-ended)
Subject:     YOUR ENERGY (mood, feelings, burnout, alignment)
Full phrase: "Discuss Your Energy"
```

### Why This Works
- **"Discuss"** = Mak is a listener, not an interrogator
- **"Your Energy"** = Specific to the person, not abstract
- Together = "Let's talk about how you're feeling"

### Visual Details
```
Icon:           💭 (thought bubble, introspection)
Button Color:   Light green (#E8F8E8)
Hover Color:    Darker green
Icon Position:  Left of text
```

### Mak Greeting
```
"How's your energy this week?"
(Opens conversation, not form-filling)
```

### What Happens
1. User clicks button
2. Mak greeting appears: "How's your energy this week?"
3. Main workspace switches to SUBJECTIVE page
4. Energy slider, mood checkboxes appear
5. Mak conversation continues: "Tell me more..."
6. Data updates in real-time

### Links To
**Page:** SUBJECTIVE (S)  
**Data:** mood_signals, energy levels, burnout indicators, value alignment

- ❌ "Create Your Roadmap" — Actionable but less conversational

## MAK PERSONALITY PER OPTION

Each option triggers a **different Mak mode**:

### Option 1: Listener & Therapist
```
Tone:       Warm, validating, non-judgmental
Focus:      How are you feeling?
Approach:   Open-ended questions, deeper exploration
Energy:     "I hear you. Tell me more."
Language:   "You," "we," "together"
Example:    "That sounds exhausting. What would help?"
```

### Option 2: Documenter & Classifier
```
Tone:       Observant, pattern-finding, practical
Focus:      What have you been doing?
Approach:   Pattern detection, gap identification
Energy:     "I see you're doing important work."
Language:   "I notice," "here's what I'm seeing," "let's"
Example:    "You've logged 47 activities. 37 are invisible.
             Want to fix that?"
```

### Option 3: Analyst & Coach
```
Tone:       Insightful, encouraging, strategic
Focus:      What's your story?
Approach:   Pattern interpretation, strength celebration
Energy:     "This is who you are."
Language:   "Your pattern," "your strengths," "your opportunity"
Example:    "You're a Clinician-Educator with emerging
             leadership. Does that resonate?"
```

### Option 4: Strategist & Sponsor
```
Tone:       Visionary, collaborative, sponsor-like
Focus:      What's your 5-year path?
Approach:   Goal-setting, roadmap-building
Energy:     "Let's build something big."
Language:   "Your goal," "let's accomplish," "you're ready for"
Example:    "You're ready for full professor. Here's
             what needs to happen."
```

### Option 5: Ghostwriter & Sponsor
```
Tone:       Enthusiastic, co-author, proud
Focus:      What are we writing?
Approach:   Evidence gathering, narrative building
Energy:     "This is your moment."
Language:   "We," "let's," "your voice," "your impact"
Example:    "Let's build your tenure case. You have
             amazing evidence here."
```

## ICON CONSISTENCY

### Icon System
All icons are **emoji** (not custom SVGs):
```
💭 = Thought (introspection, conversation)
📋 = Documentation (records, checklist)
🔍 = Investigation (analysis, discovery)
🗺️ = Navigation (strategy, direction)
✍️ = Writing (creation, authorship)
```

### Icon Placement
All icons appear **left of text** in buttons:
```
[Icon] Option Title
[Subtitle]
```

### Icon Sizing
```
In button:      24px (readable at touch size)
In header:      20px (balanced with text)
In Mak message: 16px (inline, conversational)
```
