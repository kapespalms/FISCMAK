## WHAT'S DIFFERENT FROM CANONICAL SPEC

### Frontend Only (Everything Else Unchanged)

**Changed:**
- ✅ Navigation: From page-based to icon sidebar (icon click → page switch)
- ✅ Input: From forms to conversations (Mak asks, user responds)
- ✅ Coach Mak: From optional chatbot to always-open primary interface
- ✅ Layout: Three-tier (sidebar + Mak + workspace) instead of single page
- ✅ User flow: No form fields anywhere in the product

**Unchanged:**
- ✅ Database schema (40+ tables, all the same)
- ✅ API endpoints (all the same)
- ✅ Formulas & signals (Recognition Gap, Lattice Score, etc., all the same)
- ✅ AI prompts (Mak, OpenAI classification, Claude generation, all the same)
- ✅ Privacy model (3-layer, RLS enforcement, all the same)
- ✅ Design system (colors, typography, spacing, all the same)

**Result:**
- Same powerful backend
- Much friendlier frontend
- Lower cognitive load for users
- Faster activity logging
- Better UX for physicians
